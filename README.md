程式用途
這是一個網路連線監控工具，具有以下功能：

定期執行 ping 測試：預設每分鐘對指定的 IP 位址進行一次 ping 測試
記錄連線品質數據：測量最小回應時間、最大回應時間、平均回應時間和封包遺失率
自動保存結果：將測試結果自動保存到 Excel 檔案中，便於後續分析
詳細日誌記錄：產生詳細的日誌檔案，記錄程式執行過程和可能的問題

主要功能特點

跨平台支援：自動偵測作業系統（Windows、Linux、macOS）並使用適當的 ping 指令格式
錯誤重試機制：ping 失敗時會自動重試多次
自動建立與管理檔案：如果指定的 Excel 檔案不存在，會自動建立一個新檔案
日期時間戳記：自動為輸出檔案加上日期，便於長期監控
參數可調整：可透過命令列參數調整目標 IP、ping 次數、重試次數等

如何使用
程式可以直接運行，使用預設參數（目標 IP: 10.14.29.201，Excel 檔案: ping_results.xlsx）：
bashpython ping_monitor.py
也可以指定自訂參數：
bashpython ping_monitor.py --target-ip 192.168.1.1 --excel-file my_results.xlsx -c 8 -r 2
參數說明：

--target-ip：要測試的目標 IP 位址
--excel-file：結果儲存的 Excel 檔案名稱
-c, --count：每次測試發送的 ping 封包數量
-r, --retries：ping 失敗時的重試次數

輸出目錄結構
程式會自動在執行目錄下創建 ping_results 資料夾，所有輸出檔案（Excel 和日誌）都會儲存在這個資料夾中，並自動加上當天日期作為檔名前綴。
這個工具非常適合用於長期監控網路連線品質，或是排查間歇性網路問題時使用。它提供的歷史數據可幫助分析網路連線性能，識別潛在問題。
